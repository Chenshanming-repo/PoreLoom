# Publication outputs

This directory reproduces the Bioinformatics manuscript dated 30 October 2026,
including the host decisions at the budget endpoint added to Table S5. The source
PDF hashes, table hashes, and numeric macros are recorded in
`provenance/publication_manifest.json`.

From this directory:

```bash
python -m pip install -r requirements.txt
python scripts/prepare_summaries.py
python scripts/plot_figures.py
python scripts/verify_publication.py
```

These commands use saved results, without training models or running inference.
Tables are LaTeX fragments for the current manuscript; figures are written as
PDF, SVG, and PNG. Generated figures and local checks are ignored by Git.

## Units and statistics

Repeated results use equally weighted means and sample standard deviations
(`ddof=1`, three units). The units are newly simulated groups, R9 training seeds
on one shared split, or disjoint R10 read groups. They are not independent
biological replicates. R9 partition counts and length coverage describe one
fixed split and have no replicate SD. Paired changes, enrichment ratios, and
timing acceleration ratios are calculated within each unit before summarizing.

The budget experiment uses one fixed R10 mixed group and one fixed sputum group.
Each budget has three training repeats (`replicate=0,1,2`) evaluated on the same
TEST set within that group. `host_forced_fraction` is the fraction of **all TEST
host reads** with a completed Accept or Reject decision at the budget-forced
observation. It includes both decision types. Reads without a completed decision
remain in the denominator. The column stores fractions; Table S5 shows percent.
`provenance/budget_endpoint_audit.json` records the original metric-file hashes
and the eight conditions. `budget_summary.csv` contains the new mean/SD summaries.

`timing_summary.csv` is the current mean/SD summary of `timing_raw.csv`. The
historical `timing_medians.csv` and `timing_ratios.csv` are retained as diagnostics;
the current figures and manuscript macros use raw timed repeats and paired ratios.
Min/max columns retained in some CSVs describe candidate coverage or historical
diagnostics; displayed uncertainty bands and error bars use sample SD.

## Optional reconstruction from the experiment archive

```bash
PORELOOM_RESULTS_ARCHIVE=/path/to/archive python scripts/prepare_results.py
python scripts/plot_figures.py
python scripts/verify_publication.py
```

The archive must contain the recorded `results/` and `provenance/` inputs. This
step reads completed outcomes; it does not refit or reselect models. The saved
partition counts describe the original splits and remain fixed. Read-ID split
membership, raw signals, model checkpoints, and simulation support files are
separate prerequisites for repeating the experiments, as explained in the root
README. No public download of that full archive is asserted here.
